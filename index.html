Syarat Format File .csv :

  • Pastikan baris pertama (Header) sama persis dengan kotak hijau di bawah.
  • Pisahkan antar kolom menggunakan koma ( , ).
  • Jangan ada tanda koma ( , ) di dalam tulisan Nama, Rekening, Program, atau teks lainnya.

Contoh Isi File CSV:

tanggal,donorId,sapaan,namaPanggilan,namaLengkap,whatsapp,jumlah,rekening,program
2023-10-25,DON-001,Bapak,Budi,Budi Santoso,08123456789,500000,BSI - 123456789,Sedekah Subuh
2023-10-26,DON-002,Ibu,Siti,Siti Aminah,08987654321,200000,Mandiri - 987654321,Infaq Umum
